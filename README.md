# Comparative genomics of *Bdellovibrio deliciasensis* kdesi

Scripts used in "Integrated Genome-Scale Characterization of Bdellovibrio sp. kdesi Establishes Novel Genomospecies Status and Identifies Lineage-Specific Chemosensory Reduction".

Software environment: `conda env create -f environment.yml`
Genome accessions are listed in Supplementary Table S1; the kdesi genome is GenBank CP102930 (reads: SRA SRR41874638).
